# 靈魂頻率 v3.5：線寬 22 與更鮮豔的光暈

公開頁面：https://mirrororc.github.io/test/

本版將繪圖座標從 1000 × 800 改為 **1000 × 1250**（寬 4、高 5），螢幕上的畫板在電腦、平板、手機與橫向螢幕皆維持直式 4:5。桌面畫板最寬 640px，避免過度拉高。

線條寬度從 **16 改為 22**，近白細亮芯按既有比例加粗。光暈色彩濃度係數從 0.95 改為 1.08（約增加 14%），不增加白色，不改變四色色相、擴散半徑、動態時間或取樣邏輯。

手機斷續的調查依使用者要求暫時擱置。本版沒有另行修改觸控或效能策略。

## 匯出

圖片仍固定 **1080 × 1350 / 4:5**。卡片中的作品位置為 `(150, 210, 780, 975)`，也是精確 4:5；完整等比置入畫板，沒有拉伸或裁切。標題與頁尾已重新配置以容納直式作品。

公開頁面保留四種顏色與繪圖操作，效果面板隱藏。一般個人 IG 帳號可儲存圖片，或使用手機支援的系統分享，再到 IG 完成發布。網站不自動發文。

## 保留的霓虹效果

- 接近白色的細亮芯、鮮豔色帶、外擴色暈。
- 每個落筆位置獨立計時，繪製時立即開始擴散，按住停著也會繼續。
- 較早區段比新區段寬，抬手不重設擴散進度。
- 凍結與系統減少動態效果仍有效。

## 維護與測試

來源在 `src/`；`assets/campaign.jpg` 是原始活動底圖。預設值集中在 `src/app.js` 的 `DEFAULTS`；霓虹擴散與光絲參數在 `WATERCOLOR`。

```sh
node build.cjs
npm install
npx playwright install chromium firefox webkit
npm test
```

`tests/public.cjs` 可驗證三引擎／五種尺寸及旋轉後的直式 4:5、線寬 22、繪圖、下載、凍結與分享替代流程；另用畫板四角的標記檢查匯出完整、位置正確。`tests/neon.cjs` 保留繪製中擴散與白色細芯檢查；`tests/pigment.cjs` 驗證發光核心與位置時間。實際執行範圍以結果 JSON 中的案例為準。

`versions/v3.4.html` 保留線寬 16 的上一版；更早的版本也保留。本機原有資料夾均未改寫。

瀏覽器測試含視窗尺寸與觸控模擬，未替代 iPhone 11 的實機手感、效能或 IG 分享驗收。
