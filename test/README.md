# 靈魂頻率：邊畫邊擴散的霓虹版 v3.3

公開頁面：https://mirrororc.github.io/test/

本版保留既有的四種聲音、隱藏效果面板、凍結與 4:5 匯出。v3.1 備份在 `versions/v3.1.html`，上一版水彩版在 `versions/v3.2.html`；本機歷次資料夾也保留。

## 這次的視覺與時序

1. 中央是細而接近白色的霓虹亮芯，外圍保留鮮豔色帶，再向外自然擴散。
2. 每個落筆位置有自己的 `born` 時間；繪製過程中立即開始擴散，不需等待抬手。
3. 按住停在原地，已畫出的色暈仍持續變大。繼續畫時，較舊區段比新區段更寬。
4. 放開只結束輸入，不會重設任何顏料年齡或讓光暈突然從頭出現。最後一個落筆位置經過 3.2 秒後停止擴散。
5. 凍結會同時停止所有色暈。系統啟用減少動態效果時，直接呈現完成狀態。

色彩維持藍 `#168aff`、紅 `#ff4938`、紫 `#9b32ff`、綠 `#0fc966`。近白亮芯約為色帶寬度的 20%，獨立保持亮度；白色不會填滿整條色帶。增亮合成限制於筆跡交疊，整個前景正常合成到背景，避免底圖把顏色沖淡。

## 維護

`src/watercolor.js` 提供純函式：連續單調高斯光暈核心、沿路徑等距取樣與落筆時間插值、每個發光位置的擴張狀態。繪製使用共用柔邊核心，不使用多圈寬線疊加。

`src/app.js` 的 `WATERCOLOR` 集中控制擴散開關、解析度、顏料濃度、取樣間距、初始半徑、擴散範圍、細亮芯白色比例／透明度／寬度。`COLORS` 定義四色。

既有預設值維持：線寬 14、色彩濃度 65%、平滑強度 104、暈染時間 3.2 秒、範圍 25、背景遮罩 19%、背景動態關閉。動態的 3.2 秒從每個位置落筆時計算，與 v3.2 的整筆抬手後計時不同。

```sh
node build.cjs
npm install
npx playwright install chromium firefox webkit
npm test
```

打包結果 `index.html` 自包含樣式、程式與原始活動底圖。

## 驗證

- `tests/pigment.cjs`：無環紋柔邊核心、取樣位置／落筆時間插值、較早區域較寬、按住時持續老化、減少動態效果。
- `tests/neon.cjs`：三個瀏覽器引擎實際按住滑鼠，不觸發 pointerup，量測光暈面積增加；繼續繪製後比較舊／新區段；以原生像素確認近白亮芯與飽和色帶；放開不重設、凍結、4:5 匯出。
- `tests/public.cjs`：三個引擎／五種版面，選色、觸控、凍結、旋轉、4:5 PNG 下載、系統分享成功／取消／不支援的替代流程。

`neon-while-drawing.png` 是同一筆畫在按住初期、按住約 1 秒、繼續繪製的實際對照。`neon-results.json` 保存量測結果。iOS／Android 真實手感、效能與實際 IG 發布仍需實機驗收。
