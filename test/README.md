公開路徑：https://mirrororc.github.io/test/

使用者可自由選色、用滑鼠／手指／觸控筆繪製，復原、清除、凍結，並匯出 1080 × 1350 的 4:5 PNG 圖片。無需登入本網站。效果面板隱藏，保留色票。所有繪圖與匯出都在瀏覽器完成，沒有帳號資料或作品上傳。

## Instagram 分享

分享圖片使用作業系統分享清單，是否提供 Instagram 由瀏覽器、手機與已安裝的 App 決定，無法保證指定分享到 IG。未支援系統分享時，提供 PNG 下載及手機長按圖片儲存，再由使用者開啟 IG 發布。無需把 IG 帳號交給本網站；一般個人帳號也可用上述方法。

本網站不自動發文，也無法確認 IG 的發布是否完成。網頁不提供 9:16 選項。重新整理前請先儲存作品。

## 維護與驗證

`src/index.html`、`src/styles.css`、`src/app.js`、`src/smoothing.js` 是原始碼；`assets/campaign.jpg` 是使用者提供的原始底圖。執行 `node build.cjs` 重新產生自包含 `index.html`。部署只需靜態檔案，無需後端。

```sh
npm install
npx playwright install chromium firefox webkit
npm test
```

`tests/public.cjs` 驗證三個瀏覽器引擎與五種尺寸的預設值、隱藏面板、選色、觸控／滑鼠繪圖、旋轉、凍結、4:5 PNG 下載、分享與取消／不支援分享的替代流程。設定 `TEST_URL=https://mirrororc.github.io/test/` 可對公開站重跑。分享以受控模擬驗證；iOS／Android 真實系統分享及 IG 發布仍需實機驗收。

舊的 v2 備份與 v3 實驗版保留於原本的本機輸出資料夾，本公開版不修改它們。
