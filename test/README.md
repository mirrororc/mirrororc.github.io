# 靈魂頻率：水彩擴散與鮮豔色彩版

沿用公開版的操作、隱藏效果面板、四種聲音顏色與 4:5 匯出。先前公開版另存於 `versions/v3.1.html`，本機 `frequency-studio-public` 也保留。

## 這次調整

- 以最早 HTML 的顏料雲向外生長為參考，改用連續密度場與擴散計算。移除數條不同粗細的寬光暈疊加；邊緣柔和、沒有同心環輪廓。
- 放開後沿用 3.2 秒 ease-out 暈染；半徑持續擴大，顏料分布逐漸變稀。完成後保留暈染結果，不會自動消失。
- 藍 `#168aff`、紅 `#ff4938`、紫 `#9b32ff`、綠 `#0fc966` 提高飽和度。取消白色中心線，光絲只混入 8% 的白色。
- 增亮合成只發生在筆跡交疊之間；整個前景以正常透明合成覆蓋底圖，避免淺色背景把筆跡洗白。
- 既有設定維持：線寬 14、濃度 65%、平滑 104、暈染 3.2 秒、範圍 25、背景遮罩 19%、背景動態關閉。

## 維護

`src/watercolor.js` 是可獨立測試的密度擴散模組：三次滑動盒狀卷積近似高斯擴散，相鄰半徑插值，避免半徑跳動。這是視覺近似，並非完整流體或紙張纖維模擬。

`src/app.js` 的 `WATERCOLOR` 集中控制開關、解析度、顏料濃度、初始擴散、範圍倍率、主線透明度與光絲白色比例；`COLORS` 定義四色。效果面板仍隱藏。

活動底圖來自原始使用者檔案。執行 `node build.cjs` 會將 HTML、樣式、腳本與底圖合成單一 `index.html`。

```sh
npm install
npx playwright install chromium firefox webkit
npm test
```

- `tests/pigment.cjs`：顏料質量守恆、向外擴散、無徑向環紋、半徑連續性。
- `tests/appearance.cjs`：三個引擎的可見擴散範圍、顏色保留、凍結；另產生同筆跡前後對照與四色卡片。
- `tests/public.cjs`：三個引擎／五種版面、選色、觸控、凍結、旋轉、4:5 PNG、下載與分享替代流程。

`TEST_URL=https://mirrororc.github.io/test/` 可測公開網址，`TEST_PUBLIC_SMOKE=1` 選擇三引擎的桌面與手機組合。iOS／Android 實機手感、耗電與真實 IG 分享仍需實機驗收。
