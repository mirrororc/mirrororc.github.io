Research workflow · 2026-11 · Windows

Codex × Zotero CLI

這是一項讓 AI 程式代理透過自然語言管理 Zotero 文獻的技術實踐，不是獨立的 Zotero 外掛或完整套裝產品。

架構

Codex 本機工作階段 → Zotero CLI Skill → zotero-cli → Zotero Local API → Zotero 桌面版。

已驗證

  • 讀取 Zotero 文獻資訊。
  • 建立 Collection 並重新查詢驗證。
  • 使用 Zotero 10 的本機 API 寫入授權。

尚待驗證

  • 自動建立 PDF 書目紀錄與掛載附件。
  • PDF 檔名整理、批次分類與 References 解析。
  • 第二台 Windows 電腦的完整自動化部署。

Windows 設定概要

  1. 安裝並開啟 Zotero，開啟 Settings → Advanced → Allow other applications on this computer to communicate with Zotero。
  2. 安裝 Codex CLI 與 uv。
  3. 以 uv 安裝 zotero-mcp-server，並安裝 Zotero CLI Skill。不必註冊 MCP Server。
  4. 保持 Zotero 開啟，取得本機寫入授權；以唯讀查詢及單筆 Collection 寫入測試確認。
uv tool install zotero-mcp-server==0.15.2
zotero-mcp install-skill
zotero-cli get recent --limit 5
zotero-mcp authorize-local
zotero-mcp setup-info

以上是技術紀錄而非可保證適用所有環境的一鍵安裝。請依指令的當前說明確認相容性。

資料安全

  • 不要上傳 Zotero API Key、Local API Key、完整資料庫與個人 PDF。
  • 不直接修改 zotero.sqlite 或 storage 內的檔案。
  • 批次寫入前先預覽；避免重複紀錄與意外刪除。
  • 本機 API 操作時 Zotero 必須執行，Cloud 工作階段不能直接使用本機 localhost。

技術發現

測試中，獨立的 Zotero MCP Server 可完成 JSON-RPC 初始化，但 Codex 的 MCP 整合持續握手失敗。後來改用專案提供的 CLI Skill 路線，成功完成實際讀寫；這是「可以使用 AI Agent 操作文獻庫」的概念驗證，而非 MCP 修復。
